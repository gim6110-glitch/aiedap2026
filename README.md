- 오른쪽에 원본 슬라이드 표시, 활동이 있는 슬라이드에서만 해당 활동지 표시
- 기존 브라우저별 자동저장, 이름·학교 재입력 시 이어쓰기, JSON 백업/복원, DOCX/HWPX/XLSX 내보내기 유지
- 로그인 → 목차 이동 → 15번 슬라이드 작성 → 자동저장 → 결과물 미리보기 및 파일 다운로드 브라우저 테스트 완료

## Netlify 연결·재배포
Netlify에서 이 GitHub 저장소의 main 브랜치를 연결하세요.
저장소의 `netlify.toml`이 배포 시 **자동으로** `node scripts/patch.mjs`를 실행하고 `dist` 폴더를 배포하도록 지정합니다.
별도로 명령을 입력하지 않아도 되며, 기존 사이트에는 새 커밋의 재배포를 실행하세요.
이전에 Publish directory를 '.'으로 지정했더라도 저장소의 netlify.toml을 우선 적용하는 것이 정상입니다.
원본 `index.html`은 빌드 입력으로 보존되며, 교정된 `dist/index.html`이 공개됩니다.

## 보존 및 제한사항
- 서버 계정이 아닙니다. 같은 브라우저에서 같은 성명·학교를 입력해야 기존 내용을 불러옵니다.
- 다른 기기는 JSON 백업 파일을 통해 복원합니다. 이름·학교만으로 서버 복원하는 기능은 없습니다.
- 연수생 엑셀의 원본 서식·수식과 1:1 동일하지 않을 수 있습니다. 사용 중인 활동지 문항에 대응하는 입력형 워크북입니다.
- HWPX 파일은 생성되나 한컴오피스 실제 버전에서 열기와 편집 호환성 추가 확인이 필요합니다.
- 개인정보가 포함된 학생 원자료는 업로드하지 마세요.
