# 2026 AIEDAP 모듈4 · 나의 AI 융합수업 re-design

75장의 강사 원본 PPTX 슬라이드를 이미지로 보여주고, 활동 장면에서 자기 수업 재설계 워크시트를 함께 작성하는 **로그인 없는 정적 웹앱**입니다.

## 기능
- 원본 `[모듈4] 강의안_정보_김신은.pptx` 75장을 전체 비율로 렌더링한 WebP 이미지(총 약 2.5 MB)
- 1~4차시 이동, 발표자 노트 열기/닫기, 슬라이드별 작성 단계 전환
- 0단계 성취기준 분석, 1단계 돌아보기, 1-1단계 AI융합/활용 체크, 2단계 네 유형, 3단계 여섯 렌즈, 4단계 재설계, 5단계 신구대조, 최종 발표
- 성명 + 학교별 작성 내용 **이 기기·브라우저 로컬 저장**. 새로 열고 같은 값을 입력하면 이어쓰기 가능. 서버 저장/인증 아님.
- IndexedDB에 첨부 자료 저장, JSON 백업에 자료 포함/복원
- 완료 항목 수/진행률 자동 계산, 미작성 항목 허용
- 최종 표형식 DOCX, HWPX(간소 OOXML 변환, 한컴 호환성 확인 필요), XLSX, JSON 다운로드 및 내용 미리보기
- 개인 정보 및 학생 민감정보 입력 금지 안내

## 배포
현재 GitHub의 `index.html`은 슬라이드 75장·발표자 노트·스타일·코드를 모두 포함하는 독립 실행판입니다. 별도 `slides/` 폴더가 없어도 동작합니다. 로컬 ZIP에는 개발 원본 파일도 포함합니다.
Netlify에서 New site → Import existing project → GitHub → 본 저장소 선택 → **Build command 비움**, **Publish directory `.`** → Deploy.

## 개인정보 및 백업
이 구현에는 서버 DB가 없습니다. 같은 컴퓨터의 같은 브라우저에서만 자동 복원됩니다. 다른 기기에서 계속 쓰려면 JSON 백업을 다운로드하고 새 환경에서 불러오세요. 이름/학교는 로그인 보안용이 아니므로 공용 컴퓨터 사용을 피하세요.

## 자료 충실도 관련 메모
PPTX 슬라이드 이미지는 제출된 교안을 직접 렌더링하여 배포합니다. 그러나 연수생용 엑셀 원본의 바이너리 파일은 이 실행 환경에서 읽을 수 없어, **강사 예시 워크북(10개 탭)에서 확인된 항목 및 슬라이드의 요구 사항을 따라 웹 폼을 구성**했습니다. 내보낸 XLSX도 웹 폼 기반으로 새로 생성하며 원본 엑셀의 수식/셀 병합/레이아웃을 바이트 단위로 복제하지 않습니다. 원본과 완전 동일한 양식 구현 시 엑셀 파일 접근과 대조 테스트가 필요합니다.

HWPX 내보내기는 HWPX ZIP+XML 기반의 간소 내보내기입니다. 사용 중인 한컴오피스 버전에서 여는 기능과 표 서식의 호환성은 사전 검증이 필요하며 DOCX는 문서 표 레이아웃으로 제공합니다.
